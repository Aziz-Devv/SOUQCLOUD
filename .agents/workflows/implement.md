# /implement

Implement ONLY the plan most recently approved via `/plan`. Do not implement anything the
plan did not cover.

1. Follow all rules in `.agents/rules/`, especially
   @.agents/rules/07-ai-agent-discipline.md and @.agents/rules/06-change-management.md.
2. Make the smallest coherent change that satisfies the approved plan.
3. If you discover during implementation that the plan or docs are wrong or incomplete, stop
   and report it — do not silently improvise a fix.
4. When implementation is complete, run `/verify` before reporting anything as done.
